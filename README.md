# Loan-Approval-System
**CreditWise – Machine Learning-Based Loan Approval Prediction System**

Developed a machine learning-based loan approval prediction system that analyzes applicants' financial and personal information to predict whether a loan application should be approved or rejected.

The project involves data preprocessing, exploratory data analysis (EDA), handling missing values, categorical encoding, feature engineering, and feature scaling to prepare the dataset for machine learning.

Implemented and compared multiple classification algorithms, including Logistic Regression, K-Nearest Neighbors (KNN), and Gaussian Naive Bayes. Evaluated model performance using accuracy, precision, recall, F1-score, and confusion matrix.

**Key Features:**
- Analyzed applicant details such as income, credit score, employment status, existing loans, savings, and loan amount.
- Performed data cleaning and exploratory data analysis using visualizations.
- Applied One-Hot Encoding, Label Encoding, and StandardScaler.
- Implemented feature engineering to improve model performance.
- Compared multiple machine learning classification models.
- Achieved **88% accuracy** using Logistic Regression after feature engineering.

**Technologies Used:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.
